# IRCTC in 2036 — student concept

A class-activity concept (IIIT Hyderabad, AI for PMs): what booking a train could feel like in 2036 — no form; say where you need to be, approve one door-to-door plan, and the railway keeps its promise.

**Not an official IRCTC product.** Sample data and invented trains/fares; nothing is booked or charged. Frontend only (HTML, CSS, JS; no build step).

Live site: https://sricharanperi.github.io/irctc-2036/
